# بناء تطبيق

الآن، وبعد أن استوعبت — كما نأمل — قسم _أساسيات Go_، أصبحت لديك قاعدة صلبة في أغلب ميزات لغة Go وكيفية ممارسة التطوير الموجه بالاختبار.

سيتناول هذا القسم القادم بناء تطبيق.

كل فصل سيبني على الفصل السابق، موسّعًا وظائف التطبيق كما يملي علينا مالك المنتج (product owner).

سنقدّم مفاهيم جديدة تساعدك على كتابة كود رائع، لكن أغلب المادة الجديدة ستكون تعرّفًا بما يمكن إنجازه باستخدام المكتبة القياسية (standard library) في Go.

وبحلول نهاية هذا القسم، سيكون لديك فهم قوي لكيفية كتابة تطبيق في Go بشكل تكراري، مدعومًا بالاختبارات.

- [خادم HTTP](http-server.md) - سننشئ تطبيقًا يستمع إلى طلبات HTTP ويردّ عليها.
- [JSON والتوجيه والتضمين](json.md) - سنجعل نقاط النهاية (endpoints) لدينا تُرجع JSON ونستكشف كيفية التوجيه (routing).
- [الإدخال والإخراج والترتيب](io.md) - سنحفظ بياناتنا على القرص ونقرأها منه، وسنغطي ترتيب البيانات.
- [سطر الأوامر وبنية المشروع](command-line.md) - دعم عدة تطبيقات من قاعدة كود واحدة وقراءة المدخلات من سطر الأوامر.
- [الوقت](time.md) - استخدام حزمة `time` لجدولة الأنشطة.
- [WebSockets](websockets.md) - تعلّم كيفية كتابة واختبار خادم يستخدم WebSockets.
